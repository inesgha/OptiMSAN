# Dossier de test

Placez ici le dossier de test au format Word (`.docx`) et, si besoin, son export PDF.

Il décrit les cas de test (partitions d'équivalence, valeurs limites) que vérifient
les 93 tests PHPUnit du dossier `tests/` :

```bash
php vendor/bin/phpunit
```

> Avant de publier, vérifiez que le document ne contient pas de données personnelles réelles
> (noms, e-mails, numéros de téléphone ou de CIN).
